# Подключение боевого WhatsApp (Cloud API)

Пока данные Meta не внесены, приложение работает с песочницей (`wa-mock`). Реальные сообщения не уходят.

## 1. Номер

- Номер **не должен быть зарегистрирован ни в каком приложении WhatsApp**. Если он заведён в обычном WhatsApp или WhatsApp Business, удалите аккаунт в приложении: «Настройки → Аккаунт → Удалить аккаунт».
- Номер должен принимать SMS или звонок: на него придёт код подтверждения.

## 2. Meta

1. На business.facebook.com откройте бизнес-портфолио.
2. На developers.facebook.com: «Мои приложения → Создать», тип **Business**, затем добавить продукт **WhatsApp**.
3. В WhatsApp Manager: «Номера телефонов → Добавить номер». Подтвердить кодом и задать **отображаемое имя**, его проверяет Meta.
4. В WhatsApp Manager добавить **способ оплаты**.
5. Постоянный токен: «Настройки компании → Пользователи → Системные пользователи». Добавить пользователя, назначить ему приложение и WhatsApp-аккаунт, затем «Создать токен» с правами `whatsapp_business_messaging` и `whatsapp_business_management`.
6. Пока компания не прошла верификацию, лимит — примерно 250 разных получателей шаблонов в сутки. Чтобы отправлять больше, пройдите верификацию: «Центр безопасности → Подтвердить», нужны документы ИП или юрлица.

## 3. Настройки в `.env`

```env
WA_API_BASE=https://graph.facebook.com
WA_API_VERSION=v23.0
WA_PHONE_NUMBER_ID=...        # WhatsApp → API Setup
WA_BUSINESS_ACCOUNT_ID=...    # WhatsApp → API Setup (WABA ID)
WA_ACCESS_TOKEN=...           # постоянный токен системного пользователя
WA_APP_SECRET=...             # Настройки приложения → Основное → Секрет приложения
WA_VERIFY_TOKEN=...           # любая длинная случайная строка
WA_DISPLAY_PHONE=+7 7xx xxx xx xx
```

После изменений перезапустите приложение без мока:

```bash
docker compose up -d
```

## 4. Webhook (входящие и статусы)

Meta отправляет события на **публичный HTTPS-адрес**, поэтому нужен сервер с доменом. Есть два варианта:
- VPS с доменом и обратным прокси. Например, Caddy сам получает сертификат: `reverse_proxy localhost:8080`.
- Временно, для проверки, — туннель cloudflared или ngrok до `localhost:8080`.

Как подключить:

1. В приложении Meta: WhatsApp → Configuration → Webhook.
   - Callback URL: `https://<ваш-домен>/api/webhooks/whatsapp`
   - Verify token: значение `WA_VERIFY_TOKEN`
2. Подпишитесь на поле **messages**.
3. Все входящие запросы проверяются по подписи `X-Hub-Signature-256` секретом `WA_APP_SECRET`. Запросы с неверной подписью отклоняются с кодом 401.

## 5. Шаблоны
